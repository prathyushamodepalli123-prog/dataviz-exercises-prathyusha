# Week 02 – Data Visualization Exercise

## Overview
This repository contains my Week 02 Data Visualization exercise completed as part of the Data Visualization course. The notebook introduces the fundamentals of Python for data analysis and visualization, including data manipulation and basic plotting techniques.

## Files
- `lecture02_notes.ipynb` – Jupyter Notebook containing the Week 02 exercises and notes
- Dataset used for the exercise (if applicable)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Plotly

## Learning Objectives
- Understand the basics of Python for data analysis
- Load and inspect datasets
- Perform simple data manipulation
- Create basic visualizations
- Interpret the results of the analysis

## How to Run
1. Open `lecture02_notes.ipynb` in Jupyter Notebook or JupyterLab.
2. Ensure the dataset (if any) is in the same folder as the notebook.
3. Run all notebook cells from top to bottom.

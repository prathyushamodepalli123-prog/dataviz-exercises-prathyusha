# Week 03 – Data Visualization Exercise

## Overview
This repository contains my Week 03 Data Visualization exercise completed as part of the Data Visualization course. The notebook introduces the fundamentals of data analysis and visualization using Python and Jupyter Notebook.

## Files
- `lecture03_exercise.ipynb` – Completed Jupyter Notebook
- Dataset used for the exercise

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Plotly

## Learning Objectives
- Import and explore datasets
- Perform basic data preprocessing
- Generate summary statistics
- Create visualizations to understand the data
- Draw insights from the analysis

## How to Run
1. Open `lecture03_exercise.ipynb` in Jupyter Notebook or JupyterLab.
2. Ensure the dataset file is in the same folder as the notebook.
3. Run all notebook cells from top to bottom.

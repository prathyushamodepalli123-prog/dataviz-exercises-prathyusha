# Week 04 – Data Visualization Exercise

## Overview
This repository contains my Week 04 Data Visualization exercise completed as part of the Data Visualization course. The notebook demonstrates the fundamentals of data loading, preprocessing, exploratory data analysis (EDA), and visualization using Python.

## Files
- `lecture04_exercise.ipynb` – Completed Jupyter Notebook
- Dataset used for the exercise

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Plotly

## Learning Objectives
- Load and inspect a dataset
- Perform basic data cleaning
- Explore the dataset using descriptive statistics
- Create meaningful visualizations
- Interpret insights from the data

## How to Run
1. Open `lecture04_exercise.ipynb` in Jupyter Notebook or JupyterLab.
2. Ensure the dataset file is in the same folder as the notebook.
3. Run all notebook cells from top to bottom.
